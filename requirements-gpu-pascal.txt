# CUDA userspace libraries for Pascal GPUs (Tesla P4, compute capability 6.1).
#
# These are NOT installed by scripts/install_python_deps.sh or install_debian.sh
# -- the installer deliberately stays out of the CUDA/driver layer (see
# README.md). They are the CUDA 12.x runtime + cuDNN 9.x that onnxruntime-gpu's
# CUDAExecutionProvider dynamically loads at session-create time. Debian does
# not package cuDNN at all, so these ship as pip wheels installed into the same
# virtualenv as onnxruntime-gpu.
#
# Install into the service venv, then register the wheel lib dirs with the
# dynamic loader (they land inside the venv where ld.so won't look by default):
#
#   V=/opt/daygle-ai-camera/.venv/bin/python
#   "$V" -m pip install --no-cache-dir -r requirements-gpu-pascal.txt   # ~2.5 GB
#   SP=$("$V" -c "import sysconfig; print(sysconfig.get_paths()['purelib'])")
#   printf '%s\n' "$SP"/nvidia/*/lib > /etc/ld.so.conf.d/daygle-cuda.conf
#   ldconfig
#
# See docs/tesla-p4-gpu-setup.md for the full runbook, verification, and the
# reasoning behind every pin.
#
# Why pinned to the CUDA 12.4 line specifically:
#   * Loads against the OS NVIDIA driver (e.g. 580.178.04, CUDA 13.0-capable)
#     through guaranteed backward compatibility -- a newer driver runs an older
#     CUDA runtime -- so these stay on 12.4 no matter how far the driver moves.
#     Keep in mind 580 is the last driver branch that supports Pascal at all.
#   * These exact versions still ship sm_61 cubins for Pascal. CUDA 12.8+
#     wheels drop Pascal kernels from individual libraries without a clean
#     error (kernel-launch failure or a silent fall back to CPU), and CUDA 13
#     removes Pascal outright. Do not bump these without re-verifying sm_61
#     support and CUDAExecutionProvider load (see the runbook).
#   * onnxruntime-gpu 1.20.x (the <1.21 ceiling in requirements.txt) needs
#     CUDA 12.x + cuDNN 9.x, which this set provides.
#
# nvidia-cudnn-cu12 declares a dependency on nvidia-cublas-cu12; after install,
# confirm pip did not quietly upgrade cuBLAS past the pin below. If it did,
# re-pin with a second install of the cuBLAS line.

nvidia-cuda-runtime-cu12==12.4.127
nvidia-cuda-nvrtc-cu12==12.4.127
nvidia-cublas-cu12==12.4.5.8
nvidia-cufft-cu12==11.2.1.3
nvidia-curand-cu12==10.3.5.147
nvidia-cudnn-cu12==9.1.0.70

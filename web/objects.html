Defaults

Set the default for every object, then override individual classes below. How "moving" is decided: an object is moving when its pixels are changing in the motion layer, and still when it has been absorbed into the background (a parked car, someone standing still).

Groups

A group is one label that matches any of its member classes - add animal to a zone rule and it fires for cat, dog, or any other member. Give a group a detection mode and box colour and every member uses them, unless the class has its own override below. When a class is in several groups, the smallest group wins.

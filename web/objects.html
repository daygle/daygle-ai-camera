Objects

Choose whether each object class counts when it is moving, standing still, or either, and alert when an object has been sitting still for a while - a package left in view, a pet that has settled down. Detection still runs on every cycle; this decides what becomes an event, recording, or alert.

◉

Detection Behavior

Set the default for every object, then override individual classes below. How "moving" is decided: an object is moving when its pixels are changing in the motion layer, and still when it has been absorbed into the background (a parked car, someone standing still).

🔖

Object Groups

A group is a single label that matches any of its member classes - add animal to a zone rule and it fires for cat, dog, or any other member. Create, edit, or remove groups here; they become available in the Zones page label pickers alongside ordinary classes.

🐾

Group Behavior

Set one detection mode for a whole group and it applies to every member class - unless a class has its own override in Per-Object Overrides below. When a class belongs to several groups, the smallest (most specific) group wins.

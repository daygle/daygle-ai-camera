Local vision model

AI

A vision-language model on your own server looks at event snapshots. It double-checks object alerts before they notify you, describes events in plain English, tags what it sees, and makes your footage searchable. Snapshots never leave your network when the model runs locally. Works with any OpenAI-compatible server, such as Ollama.

Model Server

Where the model runs. Every AI feature on this page uses it. If it is unreachable or slow, alerts are sent as normal. See the setup guide in docs/ai-verification.md.

💬

Descriptions & Search

The model writes a one-sentence description of each event and tags notable objects (e.g. ladder, parcel). Descriptions lead your email and push notifications, show in the Events list, and make footage searchable in plain English on the Events page.

Local vision model

AI

A vision-language model on your own server looks at event snapshots. It double-checks object alerts before they notify you, describes events in plain English, tags what it sees, and makes your footage searchable. Snapshots never leave your network when the model runs locally. Works with any OpenAI-compatible server, such as Ollama.

    False Positives
    
          
    A false positive is a detection of something that was not really there, such as a shadow read as a person. The model above can check every object event and mark the false ones, and any signed-in user can mark (or un-mark) any event, snapshot or recording from the Events, Snapshots and Recordings pages. False positives can then be purged automatically to save space.

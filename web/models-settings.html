Optional inference tuning that works on its defaults - most setups never need to touch these. Change one at a time so you can attribute any per-frame impact. Settings are grouped by where they apply: the CPU and GPU groups only affect their own device, so on a CPU-only host the GPU group is inert (and vice versa). The device actually running is shown as Device on the Object Models tab.
